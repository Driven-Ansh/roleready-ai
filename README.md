# RoleReady AI

**RoleReady AI** – a job‑specific readiness platform.

- **Tech stack**: Next.js, TypeScript, Tailwind CSS, shadcn/ui, Lucide, Recharts, Framer Motion.
- **Features**: job DNA extraction, skill X‑Ray, gap analysis, personalized roadmap, project generator, interview simulator, what‑if simulation, multi‑job comparison, ATS view, final readiness report.
- **Demo mode**: loads a pre‑configured candidate (Arjun Mehta) and a demo job (Backend Software Engineer at Nexa Systems) so the full flow works without external AI keys.

## Getting started locally
```bash
cd roleready-ai
npm install
npm run dev   # opens http://localhost:3000
```

## Deploying to Vercel
1. Push the repo to GitHub.
2. Connect the repository on Vercel (or use the Vercel CLI). Vercel will automatically install dependencies and deploy.
